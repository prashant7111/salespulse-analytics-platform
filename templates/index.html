WORKSPACE

A clear system, not a black box.

SalesPulse keeps ingestion, profiling, analytics and presentation separate so each part can be understood and extended independently.

Ingestion

CSV, TSV, Excel, JSON, JSONL and Parquet are normalized into a common table structure. API and webhook routes provide live-data paths.

Analysis

Numeric measures, dates and dimensions are detected before a chart is selected. Unsupported views explain why they are unavailable.

Security

Accounts use hashed passwords and HTTP-only sessions. A public deployment should add HTTPS, CSRF protection, rate limiting, managed secrets and role-based permissions.

Health & architecture

Checking…

The application exposes a lightweight health endpoint and keeps the analytics logic in the backend. This makes the project straightforward to deploy behind a production WSGI server later.
